01The problem

The person on the call may not be the person you hire.

Someone else sits in

A stand-in takes the interview, or a recording plays where the webcam should be.

A hidden AI reads answers

An overlay the call cannot see listens and suggests what to say.

A face swap

A live filter turns one person into another, in real time.

Why I built it

I was the founding designer at SigIQ, the team behind EverTutor. To be sure of who we hired, we flew candidates in and sat next to them during the interview. It worked, and it was slow and costly. Verified Call brings that check to remote calls.

04 · Flow

Tell the host, don't block the candidate

Decision
If another app uses the camera, the candidate sees one amber note and joins. The host sees "Needs a look".
Result
No check waits on the candidate, and the host still gets the fact.
Why, and what I tried first
Why
The check is for the host. A check that waits for the candidate's click can be skipped by never clicking.
Tried first
A hard stop. Then a choice: "Close OBS for the best result" or "Continue anyway".

ShippedFinal

05 · Presence

Never join the call

Decision
The check runs on the candidate's computer. Nothing joins the meeting.
Result
Two people in the call, and a badge on the guest's tile.
Why, and the trade-off
Why
No bot in the participant list. The call looks and feels like any other call.
Trade-off
The candidate installs a small app once, and the result shows on the host's own screen.

04How it is built

An app, an extension and a server, on one design system.

From the code · the camera notice

// QA-55: "Your host has been told that Python is using your camera."
// Each text is notified once, until it changes or goes away.
export function cameraNoticeToShow(st: CameraNoticeState, s: ConditionsSnapshot | null): string | null {
  const text = cameraNoticeText(s);
  if (text === st.shown) return null;
  st.shown = text;
  return text;
}

The candidate is told once, and told again only when the fact changes. The same rule runs the host's panel.

When one part fails, the rest keeps going"The face check couldn't start. The rest of the check keeps running."
Connection drops are calmThe app says it is reconnecting and asks the candidate to keep it open. The check carries on.
Nothing waits on a clickEvery check starts on its own. A busy camera retries, then gives the host a plain line.

06What I learned

Still concepts before motion

The particle-face hero read as uncanny. Now I show two or three still options and pick one before anything moves.

Calm is a feature

The panel got better each time it did less. A signal that stays still is a signal people trust.

No check may wait on a click

A choice screen once held the face check until the candidate pressed a button. A check that can be skipped by not clicking is not a check.
